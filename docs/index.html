Планер репетитора

Календарь занятий, карточки учеников, учёт оплат и заработка за месяц. Данные синхронизируются между устройствами и доступны без интернета.

Скачать для macOS
macOS 14 и новее · Apple Silicon и Intel · бесплатно

Первый запуск

  1. Откройте скачанный PlannerApp-macOS.dmg и перетащите «Планер» в «Программы».
  2. Запустите приложение двойным кликом. macOS покажет предупреждение — нажмите «Готово».
  3. Откройте Системные настройки → Конфиденциальность и безопасность.
  4. Пролистайте вниз до раздела «Безопасность» и нажмите «Всё равно открыть».
  5. Подтвердите паролем администратора.

Это делается один раз. Дальше приложение открывается как любое другое.

Почему macOS ругается

Приложение не прошло нотаризацию у Apple. Для неё нужен платный аккаунт Apple Developer Program, которого у проекта нет. Система не знает автора и поэтому просит подтвердить запуск вручную — это не признак того, что с файлом что-то не так.

Исходный код открыт, сборку выполняет GitHub Actions прямо из репозитория: github.com/DanilaAdm/planer. Контрольные суммы каждого релиза лежат в файле SHA256SUMS рядом с загрузкой.

Установка одной командой

Если предпочитаете терминал — эта команда скачает последнюю версию, положит её в «Программы» и снимет карантин, так что ходить в системные настройки не придётся:

curl -fsSL https://github.com/DanilaAdm/planer/releases/latest/download/install-macos.sh | bash

Аккаунт и данные

При первом запуске нужно создать аккаунт по e-mail и паролю — больше ничего настраивать не надо. Данные привязаны к аккаунту, поэтому с теми же почтой и паролем вы увидите свой календарь на другом компьютере.

Расписание, ученики и оплаты хранятся в базе PostgreSQL на Supabase. Записи каждого пользователя изолированы политиками Row Level Security: другие пользователи сервиса не могут их прочитать. Локальная копия лежит на вашем компьютере, чтобы приложение работало без интернета.
